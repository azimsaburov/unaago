# UnaaGo — Маркетплейс Аренды Автомобилей

## Описание проекта
UnaaGo — это мобильное приложение на Flutter, объединяющее компании по прокату авто и частных арендодателей с клиентами.

### Основные возможности:
- **Для арендаторов:** Поиск машин поблизости, фильтрация по параметрам, удобное бронирование.
- **Для владельцев (C2C):** Возможность сдать свой автомобиль в аренду и получить дополнительный доход.
- **Для компаний (B2C):** Управление собственным парком автомобилей через систему подписок.

## Технический стек
- **Frontend:** Flutter
- **State Management:** BLoC / Cubit
- **Network:** Dio
- **Serialization:** JsonSerializable
- **Architecture:** Feature-first

## Структура проекта
- `lib/app`: Глобальные настройки приложения и навигация.
- `lib/core`: Общие компоненты, модели данных, сетевой клиент и константы.
- `lib/features`: Отдельные модули приложения (Home, Profile, Location и др.).
- `assets/i10n`: Файлы локализации (поддержка мультиязычности).

## Как запустить
1. Убедитесь, что у вас установлен Flutter.
2. Склонируйте репозиторий.
3. Выполните `flutter pub get`.
4. Для генерации моделей запустите: `dart run build_runner build`.
5. Запустите приложение: `flutter run`.
